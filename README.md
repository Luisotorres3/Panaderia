# 🥖 Panadería App

## 🥐 Descripción | Description | Description

**Panadería** es una aplicación móvil desarrollada para ofrecer a los usuarios una manera intuitiva de explorar y comprar productos de panadería. Organiza los productos en diferentes categorías y permite gestionar la cesta de la compra, realizar pedidos y ver el historial de compras anteriores.

**Panadería** is a mobile app designed to offer users an intuitive way to explore and purchase bakery products. It organizes products into various categories, allowing users to manage the shopping cart, place orders, and view their order history.

**Panadería** est une application mobile conçue pour offrir aux utilisateurs un moyen intuitif d'explorer et d'acheter des produits de boulangerie. Elle organise les produits en différentes catégories, permet de gérer le panier, de passer des commandes et de voir l'historique des achats.

## 🏛️ Arquitectura | Architecture | Architecture

La aplicación sigue el patrón **Modelo-Vista-Controlador (MVC)**:

- **Modelo**: Maneja los datos de productos y pedidos.
- **Vista**: Gestiona la interfaz de usuario y las pantallas.
- **Controlador**: Coordina la interacción entre la vista y el modelo.
